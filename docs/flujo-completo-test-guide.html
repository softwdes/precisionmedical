Paso 1 — Landing y token

  1. Abrir el link forms.lienmaster.net/c/[token]
  2. Debe aparecer pantalla de bienvenida con nombre del paciente
  3. Verificar: datos del accidente, próxima cita, checklist del wizard
  4. Clic "Comenzar"

Pasos 2–7 — Wizard

  1. Datos personales: verificar nombre, DOB, teléfono · agregar email, contacto de emergencia
  2. Accidente: confirmar fecha, tipo, descripción detallada
  3. Seguro: aseguradora PIP, número de póliza/reclamo
  4. Historial médico: salud general, medicamentos, alergias, condiciones previas
  5. Documentos: selfie · licencia · tarjeta de seguro (o marcar "tomo en clínica")
  6. Firma de lien: leer texto completo → firmar en canvas → clic "Firmar y enviar"
  7. Pantalla final: "✅ ¡Ya registrado!"

Probar también

  • 🔴 Token inválido → mensaje de error claro, número de clínica
  • 🔴 Token ya usado → "Ya registrado" con datos del formulario
  • 📱 Abrir en móvil → wizard funciona en pantalla pequeña
  • 💾 Auto-save: verificar indicador en historial médico

A · Vista de cola del día

  1. Ir a clinic.lienmaster.net/admission
  2. Verificar KPIs: Total · Checked In · Pendientes · En sala
  3. Buscar el appointment de Test Saliente en la lista
  4. Verificar: nombre, hora, doctor, clínica, estado CONFIRMED
  5. Clic rápido en "Check-in" inline → estado cambia a CHECKED_IN

B · Detalle de admisión

  1. Clic en el nombre del paciente → abre /admission/[id]
  2. Verificar información del paciente: nombre, DOB, teléfono, email
  3. Verificar checklist de documentos:
    ☑ Formulario de intake completado
    ☑ Documentos de seguro presentados
  4. Marcar ambos ítems como verificados
  5. Clic "Admit to room"
  6. Estado del appointment cambia a IN_PROGRESS
  7. Volver a la cola → appointment ya no aparece en pendientes
Idempotencia: si el paciente ya fue chequeado (CHECKED_IN), el botón "Check-in" vuelve a hacer la llamada pero el API retorna OK sin cambiar nada. Verificar que no da error.

A · Check-in en tablet / iPad

  1. Abrir doctor.lienmaster.net/checkin/[appointmentId]
  2. Pantalla muestra datos del paciente en tamaño grande para verificación visual
  3. MA verifica verbalmente con el paciente:
    ○ Nombre completo
    ○ Fecha de nacimiento
    ○ Código del caso
  4. Verificar indicadores en pantalla: form completado (✓/○) · firma de lien (✓/○)
  5. Clic "Confirmar llegada"
  6. Se abre pad de firma → paciente firma en el tablet
  7. Nombre pre-llenado · clic "Guardar firma"
  8. Appointment queda en estado CHECKED_IN

B · Triage — signos vitales

  1. Navegar a /triage/[appointmentId]
  2. MA ingresa signos vitales:

  1. Clic "Guardar triage" → datos sincronizados al doctor
  2. Doctor abre /visit/[appointmentId] → vitales ya visibles
